RU
Установка (Chrome, Яндекс Браузер, Edge, Brave, Opera, Arc):
1. Распакуйте архив в отдельную папку.
2. Откройте chrome://extensions (в Яндекс Браузере — browser://extensions).
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку.
5. Закрепите NovaBlock-X на панели.

Новое в 1.3.0: полностью переработанный интерфейс (боковое меню:
Общие, Разрешённые сайты, Расширенные, Справка, Разработчик),
светлая и тёмная темы, русская и английская локализации.

EN
Installation (Chrome, Yandex Browser, Edge, Brave, Opera, Arc):
1. Unpack the archive into a folder.
2. Open chrome://extensions
3. Enable Developer mode.
4. Click "Load unpacked" and select the folder.
5. Pin NovaBlock-X to the toolbar.

New in 1.3.0: redesigned UI with sidebar navigation
(General, Allowlisted websites, Advanced, Help, Developer),
light/dark themes, Russian and English localization.
