📦 NovaBlock-X

NovaBlock‑X – мощное расширение для браузеров на базе Chromium, использующее технологию declarativeNetRequest для эффективной и безопасной блокировки рекламы, трекеров, раздражающих элементов и вредоносных сайтов. Работает в Chrome, Яндекс.Браузере, Edge, Brave, Opera, Arc и других.

Максимальный блокировщик рекламы и трекеров на Manifest V3

🌟 Особенности
✅ 3 режима фильтрации – от базового до максимального, с настройкой производительности.

✅ Более 25 фильтров – EasyList, EasyPrivacy, uBlock Origin, AdGuard, Peter Lowe, списки безопасности и раздражителей.

✅ Режим обучения – расширение анализирует, какие элементы вы скрываете вручную, и предлагает постоянные правила для сайта.

✅ Косметическая фильтрация – скрывает пустые блоки рекламы, улучшая внешний вид страниц.

✅ Ручное управление экспериментальными фильтрами – вы сами решаете, включать ли дополнительные списки.

✅ Статистика блокировок – интерактивные графики, топ заблокированных доменов, распределение по категориям.

✅ Свои фильтры – добавляйте собственные правила в формате Adblock Plus.

✅ Экспорт/импорт настроек – сохраняйте конфигурацию в JSON.

✅ Тёмная и светлая темы – автоматически подстраиваются под систему.

✅ Локализация – русский и английский интерфейсы.

✅ Безопасность – все данные хранятся локально, ничего не отправляется на сервер.

🔧 Установка для пользователей
Быстрый способ (для конечных пользователей)
Скачайте готовую сборку (CRX-файл) со страницы релизов или установите из магазина расширений (в разработке).

Установка из исходников (для тестирования)
Скачайте или клонируйте репозиторий.

Откройте браузер и перейдите на страницу расширений:

Chrome / Edge / Brave / Opera: chrome://extensions

Яндекс.Браузер: browser://extensions

Включите «Режим разработчика» (Developer mode).

Нажмите «Загрузить распакованное» (Load unpacked) и выберите папку с проектом.

Готово! Закрепите иконку на панели инструментов.

🛠️ Сборка из исходников (для разработчиков)
Для сборки требуется Node.js (версия 16 или выше).

Установите зависимости (не требуется, так как все скрипты написаны на чистом JS).

Откройте терминал в корневой папке проекта.

Запустите компилятор фильтров:

bash
node build.js
Скрипт скачает все фильтры, скомпилирует их в формат DNR (Declarative Net Request) и обновит manifest.json.

Для ускорения используется кэш (24 часа), поэтому при повторной сборке скачиваются только изменившиеся списки.

После успешной сборки расширение готово к установке (см. шаги выше).

Примечание: Если какой-либо фильтр недоступен (HTTP 404), он будет пропущен, и сборка продолжится с остальными.

🖥️ Использование
Всплывающее окно (поп‑ап) – показывает текущий сайт, статистику, режим, позволяет скрывать элементы.

Страница настроек – открывается через иконку шестерёнки в поп‑апе или из меню расширений.

Панель статистики – графики, категории, топ доменов.

Режим обучения – автоматически предлагает правила для сайтов, где вы часто скрываете элементы вручную.
